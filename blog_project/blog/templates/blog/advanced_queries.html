Advanced Django ORM Queries

This page demonstrates the specific ORM lookups and related-object queries used throughout the app, each shown in isolation.

2. Posts containing a keyword

BlogPost.objects.filter(Q(title__icontains="{{ keyword|default:'...' }}") | Q(content__icontains="{{ keyword|default:'...' }}")) {% if keyword %} {% if posts_with_keyword %}
    {% for post in posts_with_keyword %}
  • {{ post.title }}
    • {% endfor %}
{% else %}

No posts match that keyword.

{% endif %} {% else %}

Enter a keyword above to run this query.

{% endif %}

3. Posts with at least {{ min_likes }} like{{ min_likes|pluralize }}

BlogPost.objects.annotate(like_total=Count('likes')).filter(like_total__gte={{ min_likes }}) {% if posts_min_likes %}
    {% for post in posts_min_likes %}
  • {{ post.title }} — {{ post.like_total }} like{{ post.like_total|pluralize }}
    • {% endfor %}
{% else %}

No posts meet that like threshold yet.

{% endif %}

4. Posts with an average rating ≥ {{ min_rating }}

BlogPost.objects.annotate(avg_rating=Avg('ratings__rating')).filter(avg_rating__gte={{ min_rating }}) {% if posts_min_rating %}
    {% for post in posts_min_rating %}
  • {{ post.title }} — {{ post.avg_rating|floatformat:1 }}/5
    • {% endfor %}
{% else %}

No posts meet that rating threshold yet.

{% endif %}
